# VAIC 2026 — Topic Research

**80 Project Ideas Across 8 Challenge Tracks**

This directory contains structured, realistic AI project concepts designed to:

1. **Align with the judging criteria** — each topic is scored against: real-world applicability, AI-native architecture, 48h prototype viability, post-competition scalability, and innovation
2. **Address Vietnamese real-world problems** — not imported Silicon Valley ideas
3. **Put AI at the core** — every topic would be meaningless without the AI component
4. **Be feasible in 48 hours** — MVP scope is explicitly considered per topic

## Files

| File | Content |
|------|---------|
| `project-ideas-by-track.md` | All 80 topics (~10 per track) with full descriptions |

## Source Methodology

Each topic was developed from:
- Official VAIC 2026 track descriptions and problem statements
- Ground truth about Vietnamese enterprise, social, and government pain points
- Current AI technical maturity (what can be built as a credible MVP in 48h)
- Alignment with the judging panel's likely focus areas
